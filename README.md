# 🛒 E-Commerce Sales Dashboard | Power BI

## 📌 Overview

An interactive **E-Commerce Sales Dashboard built using Microsoft Power BI** to analyze sales, profit, quantity, customers, product categories, payment modes, geographical performance, and monthly profit trends.

The dashboard provides a consolidated view of key sales and profitability metrics with interactive quarter and state filters.

## 🎯 Objective

* Analyze overall sales and profit performance
* Track total sales quantity
* Understand sales performance across states
* Analyze product categories and sub-categories
* Identify top customers by sales amount
* Analyze preferred payment modes
* Monitor monthly profit trends
* Compare performance across quarters

## 📂 Dataset

The project uses two datasets:

### Details.csv

Contains transaction-level sales information including:

* Order ID
* Amount
* Profit
* Quantity
* Category
* Sub-Category
* Payment Mode

### Orders.csv

Contains order and customer information including:

* Order ID
* Order Date
* Customer Name
* State
* City

The two datasets are connected through the **Order ID** field.

## 🔍 Key Insights

* **Maharashtra** has the highest displayed sales amount among the states shown.
* **Clothing** contributes the largest share of quantity at approximately **63%**.
* **COD** is the most frequently used payment mode by quantity at approximately **44%**.
* **Printers** are the highest-profit sub-category among those displayed.
* **Harivansh** has the highest displayed sales amount among the customers shown.
* Monthly profit varies throughout the year, with positive and negative profit periods visible in the trend analysis.
* The dashboard allows performance to be explored interactively using **Quarter** and **State** filters.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `2nd PB.pbix` using **Microsoft Power BI Desktop**.
3. If required, update the data source paths for `Details.csv` and `Orders.csv`.
4. Explore the dashboard using the Quarter and State filters.
5. Interact with the charts to analyze sales, profit, quantity, customers, categories, and payment modes.
